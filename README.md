# Face Recognition with Machine Learning & Flask

This project is an end-to-end **Face Recognition application** built from scratch using **Python, OpenCV, Machine Learning, and Flask**. The application can detect human faces from images or a camera feed and recognize the person using a trained machine learning model.

## About the Project

The project demonstrates how **Computer Vision and Machine Learning** can be integrated into a web application. OpenCV is used for face detection and image processing, while a Machine Learning algorithm is trained to recognize different individuals based on facial features.

The project follows a complete machine learning workflow, starting from collecting and processing facial data, detecting faces, extracting relevant features, training the model, and finally using the trained model to make predictions on new images.

A **Flask-based web application** is created to provide an easy-to-use interface for the face recognition system. Users can provide an image as input, and the application processes the image, detects the face, and predicts the identity of the person.

The project also includes **deployment of the Flask application**, providing practical experience in taking a machine learning project from development to a deployable web application.

## Features

* Face detection using OpenCV

* Image preprocessing and feature extraction
